# spiders-applied-aiml-foundation

A beginner-friendly Python repository that explores core programming concepts, including variables, data types, conditional statements, data structures, loops, functions, file handling, and object-oriented programming (OOP), with easy-to-understand examples.

# Python Fundamentals 🐍

This repository contains simple Python programs that demonstrate essential programming concepts. It is intended for beginners who want to learn Python step by step and develop a solid understanding of programming fundamentals.


### 1. Variables and Data Types

**File:** `variables_datatypes.py`

* Understanding variables and assigning values.
* Working with basic data types: String, Integer, Float, and Boolean.
* Exploring collection types: List, Tuple, Set, and Dictionary.
* Identifying data types using the `type()` function.

### 2. Conditional Statements

**File:** `conditions.py`

* Using `if`, `elif`, and `else` statements.
* Accepting input from users.
* Handling invalid input with exception handling.
* Determining grades based on marks.

### 3. Data Structures

**File:** `data_structures.py`

* Lists: Ordered collections that can be modified.
* Tuples: Ordered collections that cannot be modified.
* Sets: Collections that store unique elements.
* Dictionaries: Structures that store data as key-value pairs.
* Accessing, modifying, and iterating over collection elements.

### 4. Loops and Patterns

**File:** `loops.py`

* Learning how `for` and `while` loops work.
* Displaying numbers from 1 to 10.
* Finding even numbers between 1 and 50.
* Calculating the sum of natural numbers.
* Creating patterns using stars.
* Generating multiplication tables.

### 5. Functions

**File:** `functions.py`

* Creating and calling functions.
* Understanding function parameters, arguments, and return values.
* Writing a function to display greetings.
* Checking whether a number is prime.
* Finding the factorial of a number.

### 6. File Handling

**File:** `file_handling.py`

* Creating files and writing data to them.
* Reading content from text files.
* Searching for specific words in a file.
* Adding new content to existing files.
* Working with Python's `pathlib` module for file and path operations.

### 7. Object-Oriented Programming (OOP)

**File:** `oops.py`

* Creating classes and their objects.
* Understanding the `__init__()` constructor.
* Working with attributes and methods.
* Calculating students' average marks.
* Displaying student details using class methods.

---

## 🎯 Project Objective

The goal of this repository is to provide practical examples of Python fundamentals that beginners can explore, practice, and use as a foundation for learning more advanced programming concepts.
